# Support

Use GitHub Issues for reproducible onboarding-pack defects, documentation inconsistencies, implementation questions, evidence/provenance gaps and bounded proposals. Include the affected revision/version, expected and observed interpretation, and the smallest useful evidence reference.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md).

This repository owns its on-ramp guidance and implementation aids. Upstream ARF normative authority remains external and must not be silently redefined by repository-local guidance.
