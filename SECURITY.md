# Security Policy

Security fixes are applied to current `main` and the latest supported release/on-ramp-pack version identified by repository status metadata. Older releases should be treated as unsupported unless a maintainer explicitly states otherwise.

Do not disclose undisclosed vulnerabilities in public issues. Use GitHub private vulnerability reporting when available, or contact the repository maintainer through a private channel identified on the maintainer profile.

Include the affected revision/version, reproduction steps, impact, affected onboarding guidance/evidence, and any known mitigation.

This repository is an ARF implementation/on-ramp guidance surface, not the normative ARF authority. A defect that could cause implementers to misread upstream requirements, authority boundaries, security controls, or evidence expectations must be corrected with the affected guidance/provenance explicitly identified.
